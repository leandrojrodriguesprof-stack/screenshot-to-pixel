# ATS Resume Optimizer

Uma aplicação web que compara um currículo com uma descrição de vaga e gera uma versão mais compatível com sistemas ATS (Applicant Tracking Systems), ajudando candidatos a aumentar suas chances de passar pela triagem automática de recrutadores.

## 🚀 Problema Resolvido

Muitas empresas utilizam ATS para filtrar currículos antes mesmo que eles sejam analisados pelo RH. Frequentemente, candidatos qualificados são descartados porque seus currículos não apresentam palavras\-chave, estrutura ou formatação adequadas para esses sistemas.

O ATS Resume Optimizer auxilia o usuário a:

- Identificar o nível de compatibilidade entre currículo e vaga;
- Encontrar palavras\-chave importantes presentes na vaga;
- Descobrir competências e termos que estão faltando;
- Gerar uma versão mais otimizada do currículo para ATS;
- Melhorar a apresentação das informações sem inventar experiências ou habilidades.

---

## 🔍 Como a Análise Funciona

### 1\. Inserção da Vaga

O usuário cola a descrição completa da vaga.

### 2\. Inserção do Currículo

O usuário cola seu currículo atual.

### 3\. Processamento

A aplicação:

- Extrai palavras\-chave da vaga;
- Identifica competências e requisitos;
- Compara essas informações com o currículo;
- Calcula um índice de compatibilidade ATS.

### 4\. Resultado

O sistema apresenta:

- Score ATS;
- Palavras\-chave encontradas;
- Palavras\-chave faltantes;
- Recomendações de melhoria;
- Currículo otimizado.

### 5\. Geração do Currículo ATS Friendly

A aplicação reorganiza e melhora a redação das informações fornecidas pelo usuário.

**Importante:** nenhuma experiência, habilidade, curso ou certificação é criada artificialmente.
